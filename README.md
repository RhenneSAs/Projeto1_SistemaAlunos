# 📚 Sistema de Gerenciamento de Alunos

Projeto desenvolvido em **Python** com o objetivo de praticar conceitos fundamentais de programação, como funções, estruturas condicionais, loops, dicionários e manipulação de dados.

## 🚀 Funcionalidades

O sistema possui um menu interativo com as seguintes opções:

* ➕ Adicionar aluno e nota
* 📋 Listar todos os alunos cadastrados
* 🔎 Buscar aluno pelo nome
* 🗑️ Remover aluno
* 📊 Calcular a média geral da turma
* 🚪 Encerrar o programa

## 🛠️ Tecnologias utilizadas

* 🐍 Python
* 📦 Dicionários
* 🔄 Estruturas de repetição
* 🔀 Estruturas condicionais
* ⚙️ Funções

## 💡 Objetivo

Este projeto foi desenvolvido como parte dos meus estudos em **Python**, com foco na prática de lógica de programação e organização do código utilizando funções.

O sistema utiliza um dicionário para armazenar os alunos e suas respectivas notas, permitindo realizar operações de cadastro, consulta, exclusão e cálculo de média.

## ▶️ Como executar

1. Tenha o **Python** instalado em sua máquina.
2. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

3. Entre na pasta do projeto:

```bash
cd nome-do-projeto
```

4. Execute o programa:

```bash
python sistema1.1.py
```
